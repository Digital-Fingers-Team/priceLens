# Phase 07 — UI / visual design system

Goal: looks deliberately designed for PriceLens, not AI-generated. Sharp, minimal, green + grey, glass used with intent.

## Pull the brand
Use the Figma MCP (if available) on file kM9Op5Emb7vvi7UiH3lrRG for logo, colors, any existing styles. The code must match Figma, not the other way around.

## Build the system (one source of truth: Tailwind config / CSS variables)
- Color: brand green scale + neutral grey scale. Semantic colors (success/warning/danger/info). Brand green and "success" green must be distinguishable. Contrast ≥ 4.5:1 for text, including text over glass.
- Type: one Latin + one Arabic font that pair well (check what's installed; loaded with next/font). Max ~6 sizes, 2–3 weights. Line heights tuned for Arabic too.
- Spacing: 4/8 scale only. No arbitrary values like `mt-[13px]`.
- Radius: sharp/small by default. Round only where it's the "bubble" brand moment.
- Elevation: 2–3 levels max.
- Glass recipe: one defined recipe (blur, tint, border, fallback when backdrop-filter unsupported). Used on a few key surfaces only.
- Icons: one set, one stroke width, consistent sizes. Icons only where they carry meaning.
- Product images: fixed aspect-ratio containers, object-contain, consistent background, no layout shift.
- Motion: subtle and purposeful, 150–250ms, respects prefers-reduced-motion.
- Dark mode (if exists): designed, not inverted.

## Components
Button, Input, Select, Checkbox, Card, Badge, PriceTag, StoreRow/OfferRow, ProductCard, Skeleton, EmptyState, ErrorState, Toast, Modal/Sheet, Pagination, Tabs.
Every component has all states: default, hover, active, focus-visible, disabled, loading, error. Inputs and buttons share heights.
Build a dev-only `/design-system` page showing every token and component in every state, LTR and RTL.

## Remove AI slop
Off-brand gradients and gradient text, cards-inside-cards, shadow on everything, emoji/decorative icons, badges everywhere, generic centered hero, fake stats/testimonials, excessive animation, inconsistent spacing, random font sizes, grey-on-grey text.

## Apply
Refactor every page to use only tokens and system components. Delete one-off styles. Re-screenshot all pages (3 breakpoints, both languages) to `ui-screenshots/after/`.

## Definition of done
No hardcoded colors/sizes outside the token layer (grep proves it). `/design-system` page complete. Pages visually consistent. `audit/07-ui.md` written.
