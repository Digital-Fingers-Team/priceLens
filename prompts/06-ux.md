# Phase 06 — UX (flows, placement, states)

Scope: structure, flows, placement, states, copy. Visual styling/design system is phase 07; don't restyle here beyond what a structural fix needs.

## Phase A — Understand
- Screenshot every route and key state with Playwright at 375 / 768 / 1440px, Arabic/RTL + English if bilingual, dark mode if it exists. Save to `ux-screenshots/before/`.
- Walk real flows as a user: land → search → results → filter/sort → product → compare stores → go to store. Plus auth/account/alerts.

## Phase B — Audit (`audit/06-ux.md`)

### Placement / information architecture
- For each page: what's the #1 thing the user came to do? Is it the most visible thing? What's competing with it?
- Search is the hero of the product and reachable everywhere.
- Primary actions in consistent positions across pages. Filters where expected (desktop side/top, mobile bottom sheet).
- Move, merge, or delete elements that don't earn their place. List every move.

### "Looks fine but is wrong"
- Can the user tell in 2 seconds which store is cheapest and why?
- Prices: consistent currency/format; shipping/fees clear; "last updated" on prices.
- Trust: store names/logos, outbound links clearly marked as leaving the site, no misleading "best deal" labels.
- States: loading (skeletons matching final layout, no shift), empty results with a helpful next step, errors with human message + retry, missing images, very long names, 1 vs 500 results.
- Search: suggestions/recent searches, typo-tolerance surfaced ("showing results for…"), empty query works, query kept on refresh.
- Forms: real labels, inline validation, correct mobile keyboards, loading/disabled submit.
- Touch: targets ≥ 44px, no hover-only info. Keyboard: full navigation, visible focus.
- RTL: mirrored layout, directional icons flip, mixed Arabic/English and numbers render correctly.
- Responsive: nothing overflows; mobile is designed, not shrunk desktop.
- Microcopy: tells the user what to do, not marketing fluff.

### Standards
Nielsen's 10 heuristics, WCAG 2.2 AA, e-commerce/comparison conventions.

## Phase C — Fix
