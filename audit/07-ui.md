### Design decisions (made tonight; recorded for the owner)
- **Locale routing:** English stays at today's URLs (no redirect, no SEO change). Arabic lives under `/ar/...`. A middleware rewrites un-prefixed paths to the `[locale]` segment internally, so pages stay static/ISR-capable (no cookie or header read in the root layout). No automatic language redirect from `Accept-Language`, so shared links are stable and caches aren't split. `hreflang`/sitemap per locale → phase 09.
- **Dictionaries**, not a library: typed `en.ts` (source) and `ar.ts` (must match its shape, checked by `tsc` and a unit test). Plurals via `Intl.PluralRules` (Arabic has six forms). No new dependency.
- **Digits:** Arabic UI uses Western digits in prices and numbers (`ar-EG-u-nu-latn`), as Egyptian stores do. Owner can flip it in one line.
- **Admin screens** stay English (staff-only), but RTL-safe.
- **Store data** (product titles, store names) is shown as scraped, with `dir="auto"`. Category names get Arabic labels from the dictionary by slug when one exists.
- **Brand vs success:** brand is olive Moss (#4F5A2A / #8C9C4A); success is a bluer green (#176B41 / #4CC38A), so "in stock" never looks like a brand accent. A unit test keeps their hues 40° apart.
- **One owner color changed:** dark-mode `muted` is #93969A instead of #8A8D90. The original is 4.10:1 on `brand-soft` (below WCAG AA 4.5:1); #93969A is 4.61:1 and looks the same.
- **Contact sales (D-26):** `mailto:Baraasaad006@gmail.com`; there is no /contact page.
